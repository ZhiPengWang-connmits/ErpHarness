## 8. 结论与建议

### 核心结论

1. **价格优势在电装**：采购价低25%（¥32 vs ¥40），年化可节省¥19,200/年，且已获得大批量优惠验证。
2. **技术路线不同**：电装主打铱金+超细电极+省油（踏板车市场），博世主打铂金+长寿命+高性能（中大排量市场），两者定位不重叠。
3. **供应商实力均优**：均为信用A级，交期相同，售后服务完善。
4. **电装性价比更高**：综合评分8.9 vs 8.4，价格和技术的加权优势明显。
5. **博世在特定场景有优势**：车型适配性更广（中大排量），市场销量更高，铂金材质寿命更长。

### 采购策略建议

1. **踏板车/小排量车型：优先采购电装DENSO U27ETR**。价格低25%+省油5-10%，按200支/月计算年省近¥20,000，且已有批量优惠验证。
2. **中大排量/高性能车型：保持博世BOSCH FR7DC+采购**。M12螺纹规格+高热值设计适配这些车型，铂金长寿命降低维护频次。
3. **合理配比建议**：按车型需求分配，踏板车：中大排量约6:4配比（预估市场结构），电装月120支+博世月80支。
4. **电装批量谈判**：考虑季度集中采购600-700支（利用¥29批量价），进一步将年成本降低至¥69,600。
5. **博世批量议价**：博世暂无批量报价，可尝试以电装的价格作为谈判杠杆，争取48→42元/支区间的批量采购价。
